# Sphere tracking (by cam bot)

Overhead-camera trackers for the Magnetic carousel. They follow the ball and measure its angular speed. Test videos are not included.

- [`sphere-tracker/`](sphere-tracker/): Python + OpenCV. See [`sphere-tracker/README.md`](sphere-tracker/README.md).
- [`sphere-tracker-cpp/`](sphere-tracker-cpp/): C++17 + OpenCV 4, built with CMake. A port of the Python tracker. See [`sphere-tracker-cpp/README.md`](sphere-tracker-cpp/README.md).
